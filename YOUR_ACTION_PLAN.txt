PART 3: DEPLOY BACKEND (10-15 minutes)
================================================================================

STEP BY STEP:

1. Go to Railway: https://railway.app
2. Click "New Project" → "Deploy from GitHub"
3. Select your library-management-system repository
4. Set root directory to: /backend
5. Railway auto-deploys - wait for completion

Add MySQL:
1. Click "Add Plugin"
2. Select "MySQL"
3. Click to add

Configure:
1. Click on your Laravel service
2. Go to "Variables" tab
3. Add these variables:
   - APP_ENV = production
   - APP_DEBUG = false
   - LOG_LEVEL = warning

Wait:
- Railway builds and deploys automatically
- Check logs until you see "Server running"
- This takes 10-15 minutes

SAVE THIS:
- Your Railway URL (looks like: https://xxx.railway.app)
- You'll need this for the frontend

TIME: ~10-15 minutes

AFTER THIS STEP:
  Your backend API is live and accessible.

================================================================================
PART 4: DEPLOY FRONTEND (5-10 minutes)
================================================================================

STEP BY STEP:

1. Go to Vercel: https://vercel.com
2. Click "Add New" → "Project"
3. Click "Import Git Repository"
4. Select your library-management-system repository
5. Set root directory to: ./frontend
6. Before clicking Deploy, add environment variable:
   - Name: NEXT_PUBLIC_API_URL
   - Value: https://xxx.railway.app/api
     (Replace xxx with your Railway URL from Part 3)

7. Click "Deploy"
8. Wait for deployment (2-5 minutes)

SAVE THIS:
- Your Vercel URL (looks like: https://xxx.vercel.app)
- THIS IS YOUR COLLEGE SUBMISSION URL

TIME: ~5-10 minutes

AFTER THIS STEP:
  Your frontend is live at a public URL.

================================================================================
PART 5: UPDATE BACKEND CONFIG (2 minutes)
================================================================================

Now that you have both URLs, update Railway:

1. Go back to Railway: https://railway.app
2. Select your project
3. Click on your Laravel service
4. Click "Variables"
5. Find: SANCTUM_STATEFUL_DOMAINS
6. Update the value to:
   your-vercel-frontend.vercel.app,your-railway-backend.railway.app

   Example:
   my-library.vercel.app,my-library-backend.railway.app

7. Save - Railway auto-redeploys

TIME: ~2 minutes

AFTER THIS STEP:
  Authentication is fully configured.

================================================================================
TROUBLESHOOTING QUICK REFERENCE
================================================================================

ISSUE: Frontend loads but login fails
FIX:
  1. F12 Console - check for error messages
  2. Check NEXT_PUBLIC_API_URL is set in Vercel
  3. Verify it matches your Railway URL

ISSUE: CORS error in console
FIX:
  1. Go to Railway
  2. Update SANCTUM_STATEFUL_DOMAINS with both URLs
  3. Wait for Railway to redeploy

ISSUE: API returns 404
FIX:
  1. Check Railway logs
  2. Verify migrations ran
  3. Check that Procfile is correct

ISSUE: Deployment takes too long
FIX:
  1. Railway auto-deploys (just wait)
  2. Check logs to see progress
  3. Should complete in 10-15 minutes

ISSUE: Stuck on a step
FIX:
  1. Read EXECUTE_DEPLOYMENT.md for that step
  2. Check DEPLOYMENT_GUIDE.md for detailed help
  3. Verify environment variables
  4. Check platform logs
