STEP 2: DEPLOY BACKEND TO RAILWAY
  Time: 10-15 minutes

  What you need to do:
  1. Create free account at https://railway.app (sign up with GitHub)
  2. Click "New Project" → "Deploy from GitHub"
  3. Select your repository and /backend directory
  4. Add MySQL plugin
  5. Set environment variables (see QUICK_DEPLOYMENT_STEPS.md)
  6. Railway auto-deploys - wait for completion
  7. Note your Railway URL (e.g., https://xxx.railway.app)

STEP 3: DEPLOY FRONTEND TO VERCEL
  Time: 5-10 minutes

  What you need to do:
  1. Create free account at https://vercel.app (sign up with GitHub)
  2. Click "Add New" → "Project" → "Import Git Repository"
  3. Select your repository, set root to ./frontend
  4. Add environment variable:
     NEXT_PUBLIC_API_URL={your-railway-url}/api
  5. Click Deploy
  6. Wait for completion
  7. Note your Vercel URL (e.g., https://xxx.vercel.app)

If you get stuck:

  - Still on localhost? Check .env.local isn't in /backend
